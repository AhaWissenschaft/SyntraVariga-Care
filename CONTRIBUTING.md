# Contributing / Mitmachen

Please read [MITMACHEN.md](MITMACHEN.md) and [SICHERHEIT.md](SICHERHEIT.md) before contributing.

The repository currently contains public-facing project descriptions. It has **no chosen open-source software license**. Do not assume that publishing a proposal grants rights to reuse unrelated private code or that contributions will automatically be licensed under MIT/Apache. Discuss licensing and contributor permissions **before** submitting software code.

For general suggestions, use a GitHub issue without personal or health information. A successful technical CI check means only that the published static content meets explicit reproducible checks; it does **not** certify safety, privacy law compliance, accessibility, or release readiness.

All external input is untrusted. A maintainer must review substantive changes and evidence before release.
