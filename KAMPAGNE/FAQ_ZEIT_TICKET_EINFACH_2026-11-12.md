## Fragen und Antworten (Deutsch, einfache Sprache)

**1. Was verschenke ich?**  
Eine halbe Stunde gemeinsame Zeit. Zum Beispiel zum Reden, Kaffeetrinken oder um gemeinsam eine Frage zum Handy zu klären.

**2. Kostet das Ticket Geld?**  
Nein. Die Vorlage ist kostenlos. Für den Ausdruck brauchen Sie gegebenenfalls Papier und einen Drucker.

**3. Wie bekomme ich die Karte?**  
Öffnen Sie die [Ticket-Datei](GOLDENES_ZEIT_TICKET.html) im Projekt. Laden Sie die HTML-Datei herunter und öffnen Sie sie auf Ihrem Gerät in einem Browser. Wählen Sie dort „Drucken“. Die Darstellung direkt auf GitHub ist nicht unbedingt die fertige Druckansicht.

**4. Muss ich mich anmelden oder persönliche Daten eingeben?**  
Für das Ticket selbst ist keine Anmeldung und keine Dateneingabe vorgesehen. Die Felder „Für“, „Von“ und „Wann“ können Sie nach dem Ausdruck mit der Hand ausfüllen. Für eine öffentliche Rückmeldung über GitHub-Issues ist dagegen ein GitHub-Konto erforderlich. Bitte veröffentlichen Sie dort keine persönlichen oder gesundheitlichen Angaben.

**5. Ist das eine fertige Gesundheits-App?**  
Nein. SyntraVariga Care befindet sich in Entwicklung. Das Zeit-Ticket ist eine Geschenkvorlage, kein Notrufdienst und keine medizinische Leistung.

**Mehr erfahren:** [Projektstatus](../README.md) · [Hinweise zum Mitmachen](../MITMACHEN.md)

## Short English version

**What is it?** A free printable promise of 30 minutes together.  
**How?** Download the HTML ticket file, open it in a browser and print it. GitHub's file preview is not necessarily the print view.  
**Account or data?** No account or data entry is required for the ticket itself. GitHub Issues require an account; never post personal or health data.  
**Is it a care app?** No. The project is still in development; this ticket is not medical or emergency assistance.
